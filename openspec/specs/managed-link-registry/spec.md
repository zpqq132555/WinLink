## Purpose

定义 WinLink 如何持久化受管链接记录，并提供状态检查、安全删除、移除记录和重建等管理行为。

## Requirements

### Requirement: 只管理 WinLink 自己记录过的映射关系
WinLink MUST 只持久化并展示本工具自己创建或记录过的源到目标映射，不得把系统中的其他未记录链接误当成受管数据。

#### Scenario: 打开已链接页
- **WHEN** 用户进入 `已链接` 工作区
- **THEN** 系统只展示 WinLink 注册表中存在的源任务与目标项
- **AND** 不自动把系统其他未知链接加入管理列表

### Requirement: 已链接页必须展示总览与按源详情
`已链接` 工作区 MUST 提供顶部总览摘要、左侧源任务列表和右侧源详情面板。

#### Scenario: 查看整体健康度
- **WHEN** 用户进入 `已链接` 页
- **THEN** 系统展示源任务总数、目标总数、生效数量、失效数量与已断开数量
- **AND** 系统自动运行一次状态检查

#### Scenario: 查看某个源任务详情
- **WHEN** 用户在左侧列表中选中某个源任务
- **THEN** 右侧面板展示该源的路径、类型、最近检查时间和全部目标项
- **AND** 每个目标项显示 `生效中`、`失效` 或 `已断开` 的主状态

### Requirement: 失效目标必须暴露可读的原因信息
WinLink MUST 在详情层为失效目标提供具体原因，便于用户判断后续处理动作。

#### Scenario: 展开一个失效目标
- **WHEN** 用户查看状态为 `失效` 的目标项详情
- **THEN** 系统展示如源不存在、目标不存在、目标不是预期链接、目标指向错误或访问失败等原因之一

### Requirement: 删除链接与移除记录必须是两个不同动作
WinLink MUST 区分 `删除链接` 与 `移除记录`，并分别约束其对磁盘与注册表的影响。

#### Scenario: 只移除记录不影响磁盘内容
- **WHEN** 用户对受管目标执行 `移除记录`
- **THEN** 系统从注册表中移除该管理项
- **AND** 不删除当前目标路径上的任何磁盘实体

### Requirement: 删除链接必须采用严格保护模式
WinLink MUST 只在目标对象仍与记录匹配时允许执行 `删除链接`。

#### Scenario: 安全删除匹配中的链接对象
- **WHEN** 当前目标仍是该记录对应的原始链接对象
- **THEN** `删除链接` 只删除该链接对象
- **AND** 系统保留该记录以便用户后续重建

#### Scenario: 阻止删除已不匹配的目标对象
- **WHEN** 当前目标已被删除、被替换、被改指向或无法安全确认
- **THEN** 系统拒绝执行 `删除链接`
- **AND** 向用户说明该目标已不再是可安全删除的受管链接对象

### Requirement: 失效或已断开目标必须支持重建
WinLink MUST 允许用户基于已记录的源与目标映射重建失效或已断开的目标项。

#### Scenario: 重建一个已断开目标
- **WHEN** 用户对状态为 `已断开` 或 `失效` 的目标项执行 `重建链接`
- **THEN** 系统使用已记录的源与目标映射重新进入创建流程
