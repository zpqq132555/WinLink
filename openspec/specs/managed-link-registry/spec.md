## Purpose

定义 WinLink 如何持久化受管链接记录，并提供状态检查、安全删除、移除记录和重建等管理行为。
## Requirements
### Requirement: 只管理 WinLink 自己记录过的映射关系
WinLink MUST 只持久化并展示本工具自己创建或记录过的源到目标映射，不得把系统中的其他未记录链接误当成受管数据。

#### Scenario: 打开已连接页
- **WHEN** 用户进入 `已连接` 工作区
- **THEN** 系统只展示 WinLink 注册表中存在的源任务与目标项
- **AND** 不自动把系统其他未知链接加入管理列表

### Requirement: 已连接页必须展示总览与按源详情

`已连接` 工作区 MUST 提供顶部总览摘要、左侧按源聚合后的任务列表和右侧源详情面板。左侧列表中仅当源名称、源路径和源类型全部一致时，系统才将多条受管记录视为同一受管源；如果名称相同但源路径不同，系统 MUST 继续分开显示。右侧目标表中的“选中目标”与“查看详情” MUST 分别承担操作焦点和详情展开职责，系统不得仅因用户选中某个目标项就自动展开该目标的详细说明。

#### Scenario: 查看整体健康度
- **WHEN** 用户进入 `已连接` 页
- **THEN** 系统展示源任务总数、目标总数、生效数量、失效数量与已断开数量
- **AND** 系统自动运行一次状态检查

#### Scenario: 查看某个源任务详情
- **WHEN** 用户在左侧列表中选中某个按源聚合后的任务
- **THEN** 右侧面板展示该源的路径、类型、最近检查时间和全部目标项
- **AND** 每个目标项显示 `生效中`、`失效`、`已断开`、`待同步` 或 `需确认` 的主状态

#### Scenario: 主动展开目标详情
- **WHEN** 用户在目标表中点击某个目标项的 `查看详情`
- **THEN** 系统展示该目标的原因说明、最近策略、最近同步时间和最近检查时间
- **AND** 系统仅在该用户显式展开时显示这些详细信息

#### Scenario: 相同源记录在已连接页中聚合
- **WHEN** 注册表中存在多条记录，且它们的源名称、源路径和源类型全部一致
- **THEN** 系统在左侧列表中仅显示一条受管源记录
- **AND** 该记录的详情面板中展示这些记录下的全部目标项

#### Scenario: 同名但不同路径的源记录继续分开显示
- **WHEN** 两条受管记录的源名称相同，但源路径不同
- **THEN** 系统在左侧列表中将它们显示为两条不同的受管源记录

---

### Requirement: 失效目标必须暴露可读的原因信息
WinLink MUST 在详情层为失效目标提供具体原因，便于用户判断后续处理动作。

#### Scenario: 展开一个失效目标
- **WHEN** 用户查看状态为 `失效` 的目标项详情
- **THEN** 系统展示如源不存在、目标不存在、目标不是预期链接、目标指向错误或访问失败等原因之一

### Requirement: 删除链接与移除记录必须是两个不同动作

WinLink MUST 区分 `删除链接` 与 `移除记录`，并分别约束其对磁盘与注册表的影响。对单个目标执行 `移除记录` 后，若所属受管源任务仍包含其他目标项，系统 MUST 保持当前受管源任务为选中状态，并把焦点恢复到剩余目标中的相邻项或首个目标；只有当该受管源任务因目标被移空而整体消失时，系统才可以回退到默认的首个受管源任务。

#### Scenario: 只移除记录不影响磁盘内容
- **WHEN** 用户对受管目标执行 `移除记录`
- **THEN** 系统从注册表中移除该管理项
- **AND** 不删除当前目标路径上的任何磁盘实体

#### Scenario: 移除记录后保持当前受管源任务
- **WHEN** 用户对当前受管源任务中的某个目标执行 `移除记录`
- **AND** 该受管源任务移除后仍有其他目标项
- **THEN** 系统刷新列表后继续保持该受管源任务为当前选中项
- **AND** 系统将当前目标切换到剩余目标中的相邻项或首个目标

#### Scenario: 当前受管源任务被删空后才回退默认项
- **WHEN** 用户对当前受管源任务中的最后一个目标执行 `移除记录`
- **THEN** 系统从注册表中移除整条空的受管源任务
- **AND** 系统刷新后才回退到默认的首个受管源任务

### Requirement: 删除链接必须采用严格保护模式
WinLink MUST 只在目标对象仍与记录匹配时允许执行 `删除链接`。

#### Scenario: 安全删除匹配中的链接对象
- **WHEN** 当前目标仍是该记录对应的原始链接对象
- **THEN** `删除链接` 只删除该链接对象
- **AND** 系统保留该记录以便用户后续重建

#### Scenario: 阻止删除已不匹配的目标对象
- **WHEN** 当前目标已被删除、被替换、被改指向或无法安全确认
- **THEN** 系统拒绝执行 `删除链接`
- **AND** 向用户说明该目标已不再是可安全删除的受管链接对象

### Requirement: 失效或已断开目标必须支持重建
WinLink MUST 允许用户基于已记录的源与目标映射重建失效或已断开的目标项。

#### Scenario: 重建一个已断开目标
- **WHEN** 用户对状态为 `已断开` 或 `失效` 的目标项执行 `重建链接`
- **THEN** 系统使用已记录的源与目标映射重新进入创建流程

### Requirement: 复用已连接源新增目标时必须并入已有受管源记录
WinLink MUST 在用户复用已连接源继续新增目标时，将新目标并入已有受管源记录，而不是创建重复的源记录。

#### Scenario: 从已连接源继续新增一个目标
- **WHEN** 用户在 `新建连接` 中选择某个已连接源并成功新增一个新的目标
- **THEN** 系统将该目标写入对应的已有受管源记录
- **AND** 注册表中不会新增第二条拥有相同源名称、源路径和源类型的受管源记录

#### Scenario: 已有受管源存在多个目标时继续并入
- **WHEN** 用户复用的已连接源本身已经包含多个目标
- **THEN** 系统保留原有目标记录
- **AND** 仅将本次新增的目标追加到同一受管源记录下
