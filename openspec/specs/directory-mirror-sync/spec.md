## Purpose

定义 WinLink 的目录镜像同步能力：支持把目录源真实复制到多个目标目录、检测源目录变化、在同步前识别目标本地改动，并区分“删除目标”和“移除记录”两种受管动作。

## Requirements

### Requirement: 目录镜像任务 MUST 支持首次真实复制到多个目标目录

WinLink MUST 允许用户把目录源创建为受管镜像任务，并在首次执行时把该源目录真实复制到一个或多个目标目录，而不是创建目录链接对象。

#### Scenario: 首次执行目录镜像任务

- **WHEN** 用户在新建任务中选择一个目录源，并将其配置为镜像模式后执行任务
- **THEN** 系统在每个目标路径创建与源目录内容一致的真实目录副本
- **AND** 系统为该镜像源与全部目标目录写入受管记录

### Requirement: 目录镜像同步 MUST 采用真镜像语义

WinLink MUST 在后续同步目录镜像时，以源目录为准复制新增内容、覆盖已变更内容，并删除目标目录中源目录已不存在的额外内容。

#### Scenario: 同步源目录新增或修改的内容

- **WHEN** 某个受管镜像源自上次同步后新增文件或修改现有文件，且用户执行“同步到所有目标”
- **THEN** 系统将这些新增或修改同步到该镜像源关联的所有目标目录

#### Scenario: 同步源目录删除的内容

- **WHEN** 某个受管镜像源自上次同步后删除了部分文件或子目录，且用户执行“同步到所有目标”
- **THEN** 系统从该镜像源关联的所有目标目录中删除对应内容

### Requirement: 目录镜像源变更 MUST 在启动或刷新时被检测并提示

WinLink MUST 为每个受管镜像源保存上次成功同步的基线，并在应用启动后的状态检查或用户手动刷新受管项状态时比较当前源目录与该基线；一旦发现变化，系统必须提示用户是否同步到所有目标目录。

#### Scenario: 启动应用后发现镜像源变化

- **WHEN** 应用启动后完成一次受管状态检查，且某个镜像源与上次同步基线不一致
- **THEN** 系统将该镜像源标记为待同步
- **AND** 系统提示用户是否把该镜像源同步到所有目标目录

#### Scenario: 手动刷新时发现镜像源变化

- **WHEN** 用户手动刷新受管项状态，且某个镜像源与上次同步基线不一致
- **THEN** 系统将该镜像源标记为待同步
- **AND** 系统提示用户是否把该镜像源同步到所有目标目录

### Requirement: 目标目录本地改动 MUST 在同步前要求用户确认

WinLink MUST 在执行目录镜像同步前检查各目标目录是否自上次成功同步后发生本地改动；如果发生本地改动，系统必须提示继续同步会覆盖这些改动并清理源目录中不存在的额外内容，只有在用户确认后才可继续。

#### Scenario: 同步前发现目标目录被手工改动

- **WHEN** 某个待同步镜像源的目标目录自上次成功同步后被本地改动，且用户尝试执行“同步到所有目标”
- **THEN** 系统提示该目标目录存在本地改动
- **AND** 系统明确说明继续同步会覆盖这些改动并清理多余内容
- **AND** 只有在用户确认后系统才继续执行同步

### Requirement: 删除镜像目标 MUST 删除目标目录实体

WinLink MUST 对受管镜像目标区分“删除目标”和“移除记录”两种动作；其中“删除目标”必须删除目标目录实体，“移除记录”只删除受管登记而不删除磁盘目录。

#### Scenario: 删除受管镜像目标

- **WHEN** 用户对某个受管镜像目标执行删除目标动作
- **THEN** 系统删除该目标目录实体
- **AND** 系统将该目标更新为已断开或等价的不可用状态

#### Scenario: 只移除镜像目标记录

- **WHEN** 用户对某个受管镜像目标执行移除记录动作
- **THEN** 系统仅移除该目标的受管登记
- **AND** 系统不删除目标路径上的现有目录实体
