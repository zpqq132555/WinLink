## MODIFIED Requirements

### Requirement: 已连接页必须展示总览与按源详情

`已连接` 工作区 MUST 提供顶部总览摘要、左侧按源聚合后的任务列表和右侧源详情面板。左侧列表中仅当源名称、源路径和源类型全部一致时，系统才将多条受管记录视为同一受管源；如果名称相同但源路径不同，系统 MUST 继续分开显示。右侧目标表中的“选中目标”与“查看详情” MUST 分别承担操作焦点和详情展开职责，系统不得仅因用户选中某个目标项就自动展开该目标的详细说明。

#### Scenario: 查看整体健康度
- **WHEN** 用户进入 `已连接` 页
- **THEN** 系统展示源任务总数、目标总数、生效数量、失效数量与已断开数量
- **AND** 系统自动运行一次状态检查

#### Scenario: 查看某个源任务详情
- **WHEN** 用户在左侧列表中选中某个按源聚合后的任务
- **THEN** 右侧面板展示该源的路径、类型、最近检查时间和全部目标项
- **AND** 每个目标项显示 `生效中`、`失效`、`已断开`、`待同步` 或 `需确认` 的主状态

#### Scenario: 主动展开目标详情
- **WHEN** 用户在目标表中点击某个目标项的 `查看详情`
- **THEN** 系统展示该目标的原因说明、最近策略、最近同步时间和最近检查时间
- **AND** 系统仅在该用户显式展开时显示这些详细信息

#### Scenario: 相同源记录在已连接页中聚合
- **WHEN** 注册表中存在多条记录，且它们的源名称、源路径和源类型全部一致
- **THEN** 系统在左侧列表中仅显示一条受管源记录
- **AND** 该记录的详情面板中展示这些记录下的全部目标项

#### Scenario: 同名但不同路径的源记录继续分开显示
- **WHEN** 两条受管记录的源名称相同，但源路径不同
- **THEN** 系统在左侧列表中将它们显示为两条不同的受管源记录

### Requirement: 删除链接与移除记录必须是两个不同动作

WinLink MUST 区分 `删除链接` 与 `移除记录`，并分别约束其对磁盘与注册表的影响。对单个目标执行 `移除记录` 后，若所属受管源任务仍包含其他目标项，系统 MUST 保持当前受管源任务为选中状态，并把焦点恢复到剩余目标中的相邻项或首个目标；只有当该受管源任务因目标被移空而整体消失时，系统才可以回退到默认的首个受管源任务。

#### Scenario: 只移除记录不影响磁盘内容
- **WHEN** 用户对受管目标执行 `移除记录`
- **THEN** 系统从注册表中移除该管理项
- **AND** 不删除当前目标路径上的任何磁盘实体

#### Scenario: 移除记录后保持当前受管源任务
- **WHEN** 用户对当前受管源任务中的某个目标执行 `移除记录`
- **AND** 该受管源任务移除后仍有其他目标项
- **THEN** 系统刷新列表后继续保持该受管源任务为当前选中项
- **AND** 系统将当前目标切换到剩余目标中的相邻项或首个目标

#### Scenario: 当前受管源任务被删空后才回退默认项
- **WHEN** 用户对当前受管源任务中的最后一个目标执行 `移除记录`
- **THEN** 系统从注册表中移除整条空的受管源任务
- **AND** 系统刷新后才回退到默认的首个受管源任务
