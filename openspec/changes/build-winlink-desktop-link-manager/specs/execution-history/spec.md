## ADDED Requirements

### Requirement: 每次执行完成后必须展示结果摘要
WinLink MUST 在一次校验或批量执行结束后向用户展示本次结果摘要。

#### Scenario: 一个批量执行完成
- **WHEN** 一次执行流程结束
- **THEN** 系统展示本次成功数量、跳过数量和失败数量

### Requirement: 系统必须保留轻量执行历史
WinLink MUST 保留最近执行记录，并允许用户通过独立入口回看这些记录。

#### Scenario: 打开执行历史
- **WHEN** 用户通过菜单或结果入口打开执行历史
- **THEN** 系统展示最近执行记录的时间、结果汇总和失败明细入口

### Requirement: 执行历史必须帮助用户定位失败原因
执行历史中的记录 MUST 至少保留本次任务摘要与失败信息，便于后续排查。

#### Scenario: 查看一条失败记录
- **WHEN** 用户打开一条包含失败项的执行历史记录
- **THEN** 系统展示该次执行涉及的任务摘要
- **AND** 展示失败目标及其失败原因
