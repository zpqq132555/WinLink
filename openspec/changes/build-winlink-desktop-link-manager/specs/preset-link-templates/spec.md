## ADDED Requirements

### Requirement: 首版必须提供固定预设模板
WinLink MUST 在第一版内置 AGENTS 主配置分发和 skills 目录同步两组固定预设。

#### Scenario: 浏览首版预设列表
- **WHEN** 用户进入 `预设` 工作区
- **THEN** 系统展示每个预设的名称、源/目标数量和简短说明

### Requirement: 预设必须以变量路径存储并以真实路径预览
预设模板 MUST 使用变量路径保存，但在界面上展示展开后的真实目标路径。

#### Scenario: 查看某个预设的预览
- **WHEN** 用户在 `预设` 页选中一个预设
- **THEN** 系统展示该预设展开后的真实源路径和目标路径
- **AND** 预设底层仍保留变量形式而不是写死当前用户名路径

### Requirement: 预设预览必须暴露冲突与父目录准备状态
预设预览 MUST 在执行前提示目标冲突和父目录缺失等信息。

#### Scenario: 某个预设目标已存在
- **WHEN** 预设中的某个目标路径在预览时已经存在
- **THEN** 系统在预览中明确标记该目标为冲突项

#### Scenario: 某个预设目标缺少父目录
- **WHEN** 预设中的某个目标依赖尚不存在的父目录
- **THEN** 系统在预览中提示该父目录缺失
- **AND** 该目录将作为执行时的自动准备动作处理

### Requirement: 预设必须支持直接应用与转普通任务
每个预设 MUST 既可以直接应用，也可以被转成普通待执行任务继续编辑。

#### Scenario: 直接应用某个预设
- **WHEN** 用户在预览后确认直接应用某个预设
- **THEN** 系统将该预设的映射关系送入标准校验与执行流程

#### Scenario: 将预设转成普通任务
- **WHEN** 用户选择把某个预设转成普通任务
- **THEN** 系统把等价的任务内容加入 `新建链接` 工作台
- **AND** 用户可以像编辑普通任务一样继续修改后再执行
