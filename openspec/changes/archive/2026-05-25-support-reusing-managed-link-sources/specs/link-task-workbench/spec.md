## MODIFIED Requirements

### Requirement: 每条任务必须锁定单一源类型
每条待执行任务 MUST 只允许一个源，并在源确定后锁定为文件任务或文件夹任务。用户既可以手工选择新的源路径，也可以直接复用已连接中的已有源；当任务复用了已连接源后，系统 MUST 锁定该任务的源路径和源类型，直到用户清除该选择并返回手工编辑模式。

#### Scenario: 以文件作为源创建任务
- **WHEN** 用户为某条任务选择一个文件作为源
- **THEN** 系统将该任务标记为文件任务
- **AND** 该任务后续只允许添加与文件兼容的目标

#### Scenario: 以文件夹作为源创建任务
- **WHEN** 用户为某条任务选择一个文件夹作为源
- **THEN** 系统将该任务标记为文件夹任务
- **AND** 该任务后续只允许添加与文件夹兼容的目标

#### Scenario: 选择已连接源后锁定源定义
- **WHEN** 用户在 `新建连接` 的备注名下拉中选择某个已连接源
- **THEN** 系统将该任务的源路径和源类型同步为该已连接源的定义
- **AND** 系统禁止用户继续手工修改该任务的源路径和源类型

#### Scenario: 清除已连接源选择后恢复手工编辑
- **WHEN** 用户清除当前任务所选的已连接源并改为手工输入新备注名
- **THEN** 系统恢复源路径输入、浏览和类型识别能力
- **AND** 该任务重新按普通新建源任务处理

## ADDED Requirements

### Requirement: 备注名输入必须支持复用已连接源候选
`新建连接` 工作区 MUST 在备注名输入区域提供已连接源候选列表，并允许用户在选择已有源与手工输入新备注名之间切换。

#### Scenario: 展示可复用的已连接源候选
- **WHEN** 用户展开备注名下拉列表
- **THEN** 系统展示所有可复用的已连接源候选
- **AND** 候选列表按源名称、源路径和源类型去重

#### Scenario: 同名不同路径的候选项显示路径消歧
- **WHEN** 候选列表中存在源名称相同但源路径不同的多个已连接源
- **THEN** 系统将这些候选都展示在下拉中
- **AND** 每个候选项使用 `名称 (路径)` 的形式区分

#### Scenario: 复用已连接源后仅继续新增目标
- **WHEN** 用户已经为当前任务选择了某个已连接源
- **THEN** 系统允许用户继续新增目标、删除目标或编辑目标信息
- **AND** 系统不要求用户重新设置源路径
