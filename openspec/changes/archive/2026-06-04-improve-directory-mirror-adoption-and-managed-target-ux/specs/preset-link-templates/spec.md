## MODIFIED Requirements

### Requirement: 预设预览必须暴露冲突与父目录准备状态

预设预览 MUST 在执行前提示目标冲突、目录镜像可采纳状态和父目录缺失等信息。对于目录镜像目标，系统 MUST 区分“目标已存在但可直接采纳为受管镜像”和“目标已存在且与源不一致的真实冲突”，不得把两者统一展示为普通冲突。

#### Scenario: 某个目录镜像预设目标已存在且可采纳
- **WHEN** 预设中的某个目录镜像目标路径在预览时已经存在
- **AND** 系统比较该目标目录与源目录快照后发现两者一致
- **THEN** 系统在预览中明确标记该目标为可采纳的已有镜像
- **AND** 系统说明执行时将允许用户仅登记受管记录

#### Scenario: 某个预设目标已存在且构成真实冲突
- **WHEN** 预设中的某个目标路径在预览时已经存在
- **AND** 该目标不是可采纳的已有目录镜像
- **THEN** 系统在预览中明确标记该目标为冲突项

#### Scenario: 某个预设目标缺少父目录
- **WHEN** 预设中的某个目标依赖尚不存在的父目录
- **THEN** 系统在预览中提示该父目录缺失
- **AND** 该目录将作为执行时的自动准备动作处理
