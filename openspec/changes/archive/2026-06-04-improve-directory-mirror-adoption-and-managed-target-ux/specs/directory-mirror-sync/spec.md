## MODIFIED Requirements

### Requirement: 目录镜像任务 MUST 支持首次真实复制到多个目标目录

WinLink MUST 允许用户把目录源创建为受管镜像任务，并在首次执行时对每个目标目录执行以下两种路径之一：当目标路径不存在时，创建与源目录内容一致的真实目录副本；当目标路径已存在且当前内容与源目录快照一致时，提示用户是否仅登记为受管镜像，用户确认后仅写入受管记录与同步基线而不重复拷贝。系统 MUST 在真正冲突的已存在目标上阻止采纳流程。

#### Scenario: 首次执行目录镜像任务

- **WHEN** 用户在新建任务中选择一个目录源，并将其配置为镜像模式后执行任务
- **AND** 某个目标路径当前不存在
- **THEN** 系统在该目标路径创建与源目录内容一致的真实目录副本
- **AND** 系统为该镜像源与该目标目录写入受管记录

#### Scenario: 采纳已存在且一致的目录镜像

- **WHEN** 用户执行一个目录镜像任务
- **AND** 某个目标目录已存在
- **AND** 系统比较该目标目录与源目录快照后发现两者一致
- **THEN** 系统提示用户该目标可仅登记为受管镜像
- **AND** 当用户确认后，系统仅写入受管记录、源目录同步基线和目标目录同步基线
- **AND** 系统不再次复制该目标目录内容

#### Scenario: 已存在但不一致的目标目录不可被采纳

- **WHEN** 用户执行一个目录镜像任务
- **AND** 某个目标目录已存在
- **AND** 系统比较该目标目录与源目录快照后发现两者不一致
- **THEN** 系统将该目标目录视为冲突
- **AND** 系统不把该目标目录登记为新的受管镜像目标
