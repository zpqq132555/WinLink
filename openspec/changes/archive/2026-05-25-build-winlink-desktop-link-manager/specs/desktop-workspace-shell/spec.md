## ADDED Requirements

### Requirement: 提供原生 Windows 桌面主工作区
WinLink MUST 以原生 Windows 桌面应用的形式启动，并通过主窗口承载用户的主要链接管理工作。

#### Scenario: 启动主窗口
- **WHEN** 用户启动 WinLink 可执行文件
- **THEN** 系统打开一个桌面主窗口而不是终端交互界面
- **AND** 该窗口作为用户后续创建与管理链接的主工作区

### Requirement: 通过标签页暴露三个主工作区
主窗口 MUST 提供 `新建链接`、`已链接`、`预设` 三个主标签页。

#### Scenario: 在主工作区之间切换
- **WHEN** 用户查看主窗口导航区域
- **THEN** 系统显示 `新建链接`、`已链接`、`预设` 三个标签页
- **AND** 用户可以在不离开主窗口的前提下切换这三个工作区

### Requirement: 提供首版全局菜单入口
主窗口 MUST 提供首版约定的全局菜单动作。

#### Scenario: 打开菜单栏
- **WHEN** 用户展开主窗口菜单栏
- **THEN** `文件` 菜单下提供 `退出`
- **AND** `工具` 菜单下提供 `刷新已链接状态`、`执行历史` 与 `扫描系统已有链接`
- **AND** `帮助` 菜单下提供 `关于`
